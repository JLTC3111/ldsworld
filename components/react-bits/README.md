# React Bits controls

Dock, Gooey Nav, Staggered Menu, Flying Button and Topography are the JavaScript/CSS components published by David Haz:

- https://reactbits.dev/components/dock
- https://reactbits.dev/components/gooey-nav
- https://reactbits.dev/components/staggered-menu
- https://reactbits.dev/components/specular-button
- https://reactbits.dev/backgrounds/topography
- https://github.com/DavidHDev/react-bits/tree/main/src/content/Micro/FlyingButton
- https://github.com/DavidHDev/react-bits/tree/main/src/content/Components

These components form part of Long D.’s portfolio under the MIT + Commons Clause license in [`REACT-BITS-LICENSE.txt`](../../src/vendor/REACT-BITS-LICENSE.txt). React’s license is retained alongside it. Gooey Nav supplies Home, Work, About, Contact and the language action in the desktop header. Desktop World settings sit below the location badge on the right. Mobile World settings appear in the Dock and remain accessible through the Staggered Menu when the portrait Dock is hidden. Staggered Menu is mounted only on phones (up to 720px) and coarse-pointer touch devices; resizing out of that layout closes the drawer and resumes the world.

`SpecularButton.jsx` and its CSS retain the actual [React Bits source](https://github.com/DavidHDev/react-bits/tree/main/src/content/Components/SpecularButton), including its rounded-rim shader, opposing light lobes and cursor steering. `../explore-specular-button.jsx` enhances the existing native Explore button in place, preserving its ID, click behavior, translated label and car/arrow icons. The surface and ink follow the portfolio theme. Interaction uses a 30fps ceiling, DPR up to 1.25 and a 60,000-pixel canvas; there is no automatic scan. Settled and distant pointers stop drawing. Hidden, offscreen or covered heroes cancel frames; keyboard focus also lights the edge. Constrained hardware, reduced motion and unavailable WebGL retain a static highlighted native button. Cleanup releases listeners, observers and the WebGL context.

Gooey Nav moves its selected pill only when the active menu item changes, including changes made elsewhere in the interface. Hover and keyboard focus retain ordinary text/focus styling without starting the effect. Activating the selected page does nothing; Work remains actionable inside a project detail so it can return to the project list without replaying the effect. World, Map, Help and Garage views clear desktop page selection. The lighter transition uses four particles, a 12px spread, 280ms timing, 50ms variance and restrained wobble. Text clipping follows simple pill paths instead of tracing every pixel on the CPU. Its canvas uses DPR up to 1.25 and sleeps after the transition; constrained hardware and reduced motion use a static selected pill without a WebGL animation. Runtime reduced-motion changes settle immediately. Language remains an action and does not move the selected page indicator.

The integration adds Dock item IDs and `aria-pressed`, and prevents handled toolbar navigation keys from reaching the car. Staggered Menu retains the upstream GSAP staggered layers, text/icon animations, numbering and social links. It adds translated labels, action callbacks, a close controller, inert closed links, focus trapping/return, Escape handling, reduced-motion timing and cleanup. Rapid reopen cancels a pending close animation. The existing brand supplies the logo, so the duplicate drawer logo is hidden. Purple numbering sits immediately beside each label, with a lighter dark-theme color. The mobile menu and stagger layers span the full viewport width. Its six numbered destinations scroll above a separate bottom control bar containing an icon-only dark-theme toggle and the EN/VI switcher. Both controls preserve the open menu and keyboard focus; the bar stays reachable in portrait and short landscape screens.

GSAP 3.15.0 is vendored from GreenSock’s official `dist/gsap.min.js` into `../vendor/gsap.cjs`, with only the unavailable source-map reference and trailing whitespace removed. The `.cjs` extension makes the upstream UMD export work with the local esbuild bundle. Its copyright and Standard License link remain in the source and production bundle; see [`GSAP-NOTICE.txt`](../../src/vendor/GSAP-NOTICE.txt).

`../about-topography.jsx` mounts Topography with every supplied value unchanged: blue `#4f7cff`, 22 lines, width 1.2, elevation 1, foreground 0.2, tilt 32, speed 0.25, forward direction, glow 0.6, depth of field 0.4, fog 0.35, hover lift and click pulse. The container is 600px high normally and 380px on phones or short screens. Static contours remain when WebGL2 is unavailable.

`../portfolio-controls.jsx` supplies real actions, translated labels, icon symbols and softer off-white/slate theme tokens. `npm run build:controls` bundles the controls, lazy Topography entry, CSS and one shared React runtime locally. `npm run build` refreshes those bundles before building the static site.

`../project-flying-button.jsx` lazily mounts Flying Button for the Selected Work action. The transparent flight layer spans the project stage behind its text and computer, with a stable CTA anchor and fully rounded pill shape. The integration adds an anchor reference, a refresh controller for layout changes, half-resolution simulation, a 30fps smoke limit, DPR 1.25 and a 480,000-pixel canvas cap. The lighter solver uses 12 pressure iterations and five shadow samples, with wider sample spacing to retain the original shadow reach. Gaussian density filtering, mipmaps, curl, noise and surface lighting remain; simulation/render passes drop from 39 to 23. Button physics remain smooth, and touch/reduced motion keep the ordinary pill-shaped action. Owned animation, listeners and WebGL resources are released on unmount.

The Pixel Snow component and sprite atlas have been removed. Precipitation now uses the local `../../src/weather.css` gradient layers, controlled by `../../src/weather-overlay.js`, with no WebGL particles or per-frame JavaScript animation.
